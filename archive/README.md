# Website archive

The active website is in the repository root. Nothing in this folder is included in the static build or served by the backend.

- old-website/: exact admin-panel source from original production commit a3d8a22c7b756551a4c1f8cd0c478a4482b780cf, before the redesign. Files are unchanged and retained on GitHub. Credentials and private runtime records were never part of that source snapshot.
- retired-media/: removed pitch markup, film and poster retained for later use, excluded from publication.
- previous-documentation/: preserved historical release and handover documents. Use the root documentation for the current layout.
- design-drafts/: earlier local redesigns and the former final preview. Excluded from Git and hosting.
- local-backups/: private copies of original working files, uncommitted documentation and security work. Excluded from Git and hosting.
- release-workspace/: temporary isolated release checkout, retained locally and excluded from Git and hosting.

Do not deploy archived folders or follow their old deployment settings.
